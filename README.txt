PAKET WEBSITE MASJID JAM'I BAITURRAHMAN - PERBAIKAN FOTO

PENTING UNTUK GITHUB PAGES:
1. Ekstrak ZIP ini.
2. Buka folder hasil ekstrak.
3. Upload SEMUA isi folder ke repository GitHub (bukan hanya file HTML).
4. Pastikan folder images ikut ter-upload dan berada sejajar dengan index.html.
5. Di GitHub, pastikan nama folder persis: images (huruf kecil).
6. Setelah commit, tunggu GitHub Pages selesai deploy lalu muat ulang situs.

Struktur wajib:
index.html
galeri.html
style.css
script.js
images/
  masjid-1.png
  dkm-logo.jpg
  irmas-logo.png
